# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `0.1.x` | Yes |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report them privately via **GitHub Security Advisories** ("Security" tab -> "Report a vulnerability" in this repository).

Please include:
- A description of the vulnerability and potential impact
- Minimal reproduction steps or a sanitized lockfile fixture
- Affected `lockmatrix` and Node.js versions

We will acknowledge receipt within 72 hours and work on a fix and coordinated disclosure.
